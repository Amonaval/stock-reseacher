# Research Stage Contracts

A stage is not complete merely because code ran without exception.

It is complete only when it produces a useful, inspectable investor-facing result.

## Stage 1 — Methodology

Must show:
- source screens analyzed
- parameters/philosophies learned
- generated strategies
- methodology support/evidence
- editable query/philosophy
- export/import capability

User control:
- enable/disable
- edit
- preview
- save profile

## Stage 2 — Screening

Must show:
- each strategy executed
- query used
- result count
- unique candidate count
- exact company identity/URL when available
- matched strategy provenance

User control:
- prune candidate universe
- require minimum strategy overlap
- manually include/exclude
- cap next-stage population

## Stage 3 — Financial Research

Must show for each company:
- evidence/data coverage
- multi-period trend observations
- qualitative dimension labels
- material warnings
- system decision
- reason
- missing financial evidence

User control:
- override research eligibility
- retry missing data
- inspect raw financial history

A numeric financial score alone does not satisfy this contract.

## Stage 4 — Company Research

Must show for each researched company:
- sources attempted
- sources successfully acquired
- document types collected
- evidence items extracted
- business-model summary
- growth drivers
- material risks
- management/capital-allocation observations
- governance observations
- catalysts
- unresolved research questions
- research coverage/readiness

User control:
- request more research
- add/remove source
- mark a question important
- continue despite incomplete evidence
- hold a company despite positive research

If no usable evidence was acquired, the stage must visibly say `SOURCE_GAP` rather than appearing complete.

## Stage 5 — Progressive Deep Research

Must show:
- current research population
- stage budgets
- why each company receives a given research depth
- what additional questions are being investigated
- held companies and reasons

User control:
- change budgets
- move a company deeper/shallower
- select explicit companies for deeper research

This stage allocates research effort. It must not pretend to be conviction ranking.

## Stage 6 — Adversarial Research

Must show:
- independent Bull case
- independent Bear case
- evidence IDs supporting each side
- thesis assumptions
- invalidation conditions
- contradictions
- unresolved disputes
- neutral challenge result
- thesis fragility

User control:
- add a missing Bear/Bull question
- force another research round
- exclude a weakly researched company from challenge

## Future Stage — Valuation

Must show:
- valuation method
- assumptions
- scenarios
- historical/peer context where appropriate
- sensitivity
- downside case
- evidence source for assumptions

Valuation attractiveness must remain separate from business quality.

## Future Stage — Conviction

Must explicitly combine, but not conflate:
- business quality
- evidence quality
- thesis resilience
- valuation
- risk
- unresolved uncertainty

Conviction must explain itself in words.

## Global completion rule

Every major stage must answer five questions:

1. What did the system do?
2. What did it learn?
3. What evidence supports that?
4. What is still unknown?
5. What happens next?

If one of these is absent, the stage is incomplete from the investor's perspective.
